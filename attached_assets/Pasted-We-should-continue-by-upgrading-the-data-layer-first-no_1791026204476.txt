## BUDGET VARIATION

The recommendation engine must calculate affordability using the user's actual budget.

Do not simply select three fixed destinations.

For every destination:

1. Calculate fuel.
2. Calculate accommodation.
3. Calculate food.
4. Calculate activities.
5. Calculate total trip cost.
6. Calculate money remaining.
7. Determine whether it is affordable.

## EXPERIENCE MATCHING

A destination may match several experiences.

Examples:

Fishing user → prioritise destinations tagged Fishing.

Beach user → prioritise Beach.

Hiking user → prioritise Hiking/Nature.

Camping user → prioritise Camping/Outdoors.

Family user → prioritise Family.

Couples user → prioritise Couples/Nature/Beach where appropriate.

Road Trip → consider all suitable destinations.

Any → consider all destinations.

Do not eliminate reasonable destinations unnecessarily. Use category matching as a relevance factor.
