8. VEHICLE AND FUEL ENGINE
==========================

Maintain the existing fuel calculation logic.

Inputs:

* vehicle
* fuel type
* consumption L/100km
* fuel price
* fuel already in tank

Trip calculation:

returnDistance =
oneWayDistance × 2

litresConsumed =
returnDistance × consumption / 100

trueFuelCost =
litresConsumed × fuelPrice

additionalFuelPurchase =
MAX(0, trueFuelCost - fuelAlreadyOwned)

IMPORTANT:

Distinguish between:

1. FUEL ALREADY OWNED
2. ADDITIONAL FUEL THAT MUST BE PURCHASED
3. TRUE FUEL CONSUMED

Example:

Fuel already in vehicle:
R650

Trip consumes:
R1,050

Additional fuel purchase:
R400

True economic fuel cost:
R1,050

Cash required now:
R400

The trip budget calculation should use the appropriate cash-spend logic while clearly displaying the true fuel consumption.
