---
name: Build My Weekend MVP scope
description: The agreed product scope for Build My Weekend.
---

Build My Weekend is an evaluation MVP, not a production tourism platform. Keep the app limited to its budget-based trip planner and clearly labeled demonstration data; do not expand it into accounts, payments, booking, external services, AI, or a complex backend without a new user request.

**Why:** The MVP is intended to test the core idea with real people before development expands.

**How to apply:** Keep future changes within the supplied MVP brief unless the user explicitly broadens the scope.
